Wavelength Updates!

August 2026

  • Shuffled clue order: clue pairs now come up at random rather than working down the list, so a group that plays twice does not get the same opening both times. A pair still will not repeat until every pair has been played. Turn it off in the clue editor to go back to list order.
  • Retired the /julie deck: it was built for a one-off event and now redirects to the home page.
  • An audience screen: a second window that mirrors the game for the room, with the target hidden behind a sliding hatch, the needle moving live, the scoring animations, the round progress and the final score card. Full screen with F.
  • A redo for spoiled rounds, and a gated handover between turns so the psychic's screen is never shown by accident.
  • Winner celebration: confetti and a final score card once the last round is played.
  • Named clue decks: save the list you are editing under a name, then load or delete it later from the editor.
  • Editor game options: show or hide the round progress bar, and set how many rounds a game runs for.
  • Background music on by default, and a draggable needle.
  • Fixes: the target can now land anywhere on the dial including the bull's-eye, round state actually restores on reload, and the dial stays centred with the spectrum labels along its bottom edge.

March 2026

  • A clue editor: add, edit and bulk-paste your own clue pairs, kept in your browser. The game reads them instead of a list baked into the page.
  • A visual rework after the official app: a warp starfield background, synthesised sound, inline SVG icons with On/Off states for the side controls, and a wave favicon.
  • Deploys moved to GitHub Actions and now queue rather than cancel, so a pushed commit cannot be left unpublished.
